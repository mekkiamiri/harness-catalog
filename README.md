# harness-catalog

Open-source harnesses for [Claude Code](https://code.claude.com): plugins that bundle skills, an MCP server and hooks, installable in two commands.

```
/plugin marketplace add mekkiamiri/harness-catalog
/plugin install <harness>@harness-catalog
```

| Harness | What it does |
|---|---|
| [ai-radar](plugins/ai-radar/) | Know about new AI tools, models and papers the day they ship: a guided daily session with dense summaries, adaptive labs, language trends, conferences and CFP alerts. [Live demo with fictional data](https://mekkiamiri.github.io/harness-catalog/ai-radar/). |
| [pc-advisor](plugins/pc-advisor/) | Buy the right computer for dev and local AI: describe your need, get a ranked list of real offers (new and refurbished, France and EU) with prices read on the shops' pages and the traps already checked (soldered RAM, weak CPU, return policy). English + [français](plugins/pc-advisor/README.fr.md). |

Only code lives here. Every harness keeps its users' results on their own machine.
